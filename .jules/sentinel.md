## 2025-05-15 - [Broken Access Control and SSRF Prevention]
**Vulnerability:** Several actions in `RoomController` were missing from `getAccessRules()`, allowing potentially unauthorized access. Furthermore, actions like `actionOpen`, `actionDetails`, and `actionViewEvent` lacked container-level visibility checks, allowing users to potentially access meetings or recordings from spaces they shouldn't have access to (IDOR). In `WebhookController`, URLs from 8x8 JaaS were saved without validation, posing a minor SSRF risk if the webhook source were compromised or spoofed.
**Learning:** In a modular system like HumHub, it's critical to not only check global module permissions but also verify access to the specific content container (Space/Profile) the object belongs to.
**Prevention:** Always include all controller actions in `getAccessRules` and implement explicit visibility/permission checks for objects associated with content containers. Use `yii\validators\UrlValidator` for any external URLs received via webhooks.
